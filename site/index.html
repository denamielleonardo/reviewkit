Get started

Install Git for Windows

Make sure you can already git fetch your GitHub repos. ReviewKit uses your existing git credentials.

Unzip and run

Extract ReviewKit.zip to a folder such as C:\Tools\ReviewKit, then open ReviewKit.exe.

Connect Claude

Go to Settings → Sign in with Claude, finish signing in in your browser, then click Refresh and Test connection.

The app isn't code-signed, so Windows SmartScreen may say "Windows protected your PC". Click More info → Run anyway. If an older download shows "Failed to resolve Python.Runtime", download this version again. To update, download again and replace the folder. Your settings and history are kept.
